# デザイン方針(トンマナ)

このサイトの配色・フォント・コンポーネントのルールをまとめたドキュメント。デザインを変更する際はここも合わせて更新する。

## 参考サイト

- https://morohoshi.site/ (Shizuku Morohoshi氏のポートフォリオ、STUDIOで制作)
- 確認できた特徴:
  - 配色はほぼ完全なグレースケール(黒〜白の細かい階調)で、アクセントカラーは控えめ
  - 見出し・本文ともに明朝体(セリフ)は使わずゴシック(サンセリフ)で統一。日本語見出しには有料フォント「A1ゴシック」を使用
- ユーザーからのスクリーンショット指定(2026-08-19)で採用した要素:
  - **左サイドバーのナビゲーション**(上部の横並びナビではなく、左固定メニュー。プロフィール名+アイコン付きナビ+SNSリンクを縦に並べる構成)
  - **角丸の囲い**(MVの大きな画像やカードが角丸の枠で囲われている。TOPページのヒーロー、WORKSカードに採用)
  - **ゴシック体で統一**(採用済み)
  - **制作実績のカテゴリ分け**(ピル型のフィルタボタン「All / Graphic / Web / Illustration...」+大きめの画像カードを並べるグリッド)
- 注記: 動的にコンテンツを読み込むサイトのため、レイアウトの余白やアニメーションの細部までは自動取得できていない。ユーザー提供のスクリーンショットを元に、配色・フォント・レイアウト構造を参考にしている(素材やイラストは独自のプレースホルダーに置き換え)

## カラーパレット

`css/styles.css` の `:root` で定義。

| 変数 | 値 | 用途 |
|---|---|---|
| `--bg` | `#f5f5f5` | ページ背景 |
| `--surface` | `#ffffff` | カード・ヘッダーなどの前面 |
| `--text` | `#1a1a1a` | 本文テキスト |
| `--muted` | `#616161` | 補足テキスト・ラベル |
| `--border` | `#e5e5e5` | 罫線・カード枠 |
| `--accent` / `--accent-strong` | `#222222` / `#000000` | ボタン・ホバー時の強調 |

アクセントカラー(有彩色)は使わず、黒〜グレー〜白の階調のみで構成する。

## フォント

- 見出し(`--font-heading`): **Zen Kaku Gothic New**(Google Fonts)。参考サイトの「A1ゴシック」(有料)に近い、クリーンでやや現代的な和文ゴシックとして採用
- 本文(`--font-body`): **Noto Sans JP**
- どちらもゴシック体で統一し、明朝体などのセリフ体は使わない

## レイアウト構造

- **左サイドバー固定** (`.sidebar`): 画面幅880px以上で常時表示。プロフィール(アバター+名前)、ナビリンク、SNSリンクを縦に配置
- **モバイル**: 880px以下でサイドバーは画面外に隠れ、上部の`.mobile-topbar`のハンバーガーボタンで開閉するドロワー方式
- **コンテンツ領域** (`.content`): サイドバーの右側、ページごとの内容を表示

## コンポーネントのルール

- **角丸の囲い**: TOPページのヒーロー(`.hero-card`)、WORKSカードの画像枠(`.work-thumb`)など、写真・イラスト枠は大きめの角丸(20〜28px)で囲う
- **カード** (`.card`, `.project-card`): 角丸は控えめ(4px)、境界線+薄いシャドウ。ホバーで4px浮き上がる
- **ボタン** (`.button`): 塗りは黒(`--accent-strong`)、角は完全な丸型(pill)。ホバーで少し不透明度を下げつつ上に浮く
- **フィルタピル** (`.filter-pill`): WORKS一覧のカテゴリ絞り込み。選択中/ホバーで黒塗りに反転。分類データは「できること・形としてイメージできるもの」を軸にした大分類3つ(デジタル・Web系/グラフィック・印刷/ブランディング・CI/VI)の下に細かい分類がぶら下がる二階層構造(`js/category-groups.js`の`CATEGORY_GROUPS`)だが、表示上は大分類ラベルを出さず全ピルを一列に並べる(ラベル区切りだと見た目が揃わず気持ち悪いため)。該当作品が無い分類はピル自体を非表示にする
- **ナビゲーション**: 現在地のリンクは色の変化で示す(`.sidebar-nav a.is-current`)
- **ページ内側の見出し** (`.page-header`): TOP以外の各ページ共通で使う、罫線区切りの小さめヒーロー
- **作品詳細モーダル** (`.detail-modal` / `.detail-modal-backdrop`): WORKS一覧で作品カードをクリックすると、画面右から幅58vw(最大640px、モバイルは全幅)のパネルがスライドインして詳細を表示する「半分モーダル」形式。背景クリック・×ボタン・Escapeキーで閉じる。URLは`work-detail.html?id=`にpushStateで書き換わるため、直接アクセス・共有・リロード時はフルページ版(`work-detail.html`)が同じ内容を表示する
- **作品詳細のレイアウト** (`.work-meta-list`, `.work-detail-link`): タイトル→タグ(カテゴリ+「Clientwork」)→説明文→Client/Scope/Yearのラベル・値リスト→区切り線→URLリンク、というコンパクトな構成に統一。フルページ版・モーダルの両方で`js/work-render.js`の`renderWorkDetailHTML()`を共通利用
- **TOPページのWorksセクション**: 静的な3カテゴリ紹介ではなく、大分類3つそれぞれから最大3件をランダムに選んで実際の作品カードを表示する(`js/top-works.js`、`.work-card`を`js/work-render.js`の`renderWorkCardHTML()`で共通生成)。再読み込みのたびに表示が入れ替わる
- **FAQアコーディオン** (`.faq-item`, `.faq-question`, `.faq-answer`): 質問行(角丸16px・枠線・白背景)をクリックすると回答が開閉する。右側の「＋」アイコンは開くと縦棒が縮んで「−」になる(色は`--text`のみ、有彩色なし)。開閉アニメーションは`grid-template-rows`のトランジションで実装(`js/faq.js`はクラス付け替えのみ)。参考サイト(morohoshi.site)のNewsセクションのアコーディオンを踏襲する想定だが、環境上ブラウザで実際の見た目を確認できなかったため、既存のモノトーン角丸デザインに合わせた標準的な実装にしている

## 今後の調整余地

- ホバーアニメーションの種類(フェード/拡大縮小など)はDay6の横断チェックで統一・追加予定
