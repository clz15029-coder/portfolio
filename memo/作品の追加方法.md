# 作品を追加する方法

WORKS一覧ページ・作品詳細ページ(フルページ版)・作品詳細モーダル(一覧からクリックした時に出る半分パネル)は、すべて `js/works-data.js` という1つのファイルの中身から自動的に作られています。新しい作品を追加するときは、このファイルを編集するだけでOKです(HTMLは触らなくて大丈夫です)。

「業務での制作実績」だけでなく、「個人制作」「イラスト」もすべて同じ`works-data.js`の配列で一緒に管理しています。

## 手順

1. `js/works-data.js` を開く
2. 配列の中にある作品データのどれか1件分(`{ id: '01', ... }` から、対応する `}` まで)を丸ごとコピーする
3. 配列の最後(一番最後の作品データの後、`];` の手前)に貼り付ける
4. 貼り付けたブロックの中身を、新しい作品の情報に書き換える

| 項目 | 説明 |
|---|---|
| `id` | 他の作品と重複しない番号。例: `'30'` |
| `title` | 案件名 |
| `client` | クライアント名。個人制作の場合は「個人制作(◯◯)」のように書く。作品詳細の「Client」欄に表示される |
| `category` | `'web'` / `'logo'` / `'print'` / `'banner'` / `'personal'`(個人制作) / `'illustration'`(イラスト) のいずれか。WORKS一覧のフィルタボタンに使われる |
| `tags` | 一覧カードに表示するタグ。例: `['WEB']` |
| `period` | 制作期間。作品詳細の「Year」欄には、この中の年(西暦4桁)を自動で抜き出して表示する。まだ決まっていない場合は`'XXXX(要変更)'`のように仮の値を入れておくと、後で直し忘れを防げる |
| `role` | 担当領域・対応範囲。作品詳細の「Scope」欄に表示される |
| `url` | 公開URL。なければ空文字 `''` のままでOK(その場合、詳細画面のリンク行は表示されない) |
| `summary` | 説明文の1行目 |
| `points` | 説明文の続き。配列でいくつでも追加でき、それぞれ1つの段落として表示される。無ければ`[]`でOK |
| `process` | 制作プロセスのデータ(現在は詳細画面に表示していないが、データとして残しておける)。`{ stage: '見出し', note: '説明文' }` を配列で並べる。無ければ`[]`でOK |

5. 保存して commit・push すれば、一覧ページ・詳細ページ・モーダルすべてに自動で反映される

## 書くときの注意点

- 文字列は必ず `'　'`(シングルクォート)か `"　"`(ダブルクォート)で囲む
- 項目と項目の間は `,`(カンマ)で区切る。ただし最後の項目の後にはカンマを付けない
- `{ }` や `[ ]` の数が対応しているか確認する(既存のブロックをコピーして作れば基本的にずれない)
- 1文字でも記号がずれるとページ全体が真っ白になることがある。保存したら一度ブラウザで表示を確認する

## 「個人制作」「イラスト」カテゴリについて

WORKS一覧のフィルタピルには、業務の制作実績(WEB/ロゴ/印刷物/バナー・グラフィック)に加えて「個人制作」「イラスト」が並んでいます。`category`を`'personal'`または`'illustration'`にすると、そのカテゴリに分類されます。

- `id: '07'`(卒業制作 - wan-idea): `category: 'personal'`
- `id: '08'`(イラスト制作): `category: 'illustration'`

## PDFポートフォリオから仮登録した実績について

`id: '09'`〜`'29'`の21件(産業廃棄物処理〜60周年記念ロゴ)は、PDFポートフォリオの31〜34ページから仮で登録したデータです。`client`・`period`・`summary`が`'XXXX(要変更)'`や「未入力」のままになっているので、正式な内容に差し替えてください。タイトルも業界名などの仮ラベルのままです。

## 作品画像について(現時点で未対応)

今のところ、WORKS一覧・詳細ページ・モーダルの画像は「作品画像(準備中)」というプレースホルダー表示のままで、実際の画像を差し込む仕組み自体がまだ実装されていません。実際の画像を掲載する際は、`images/works/` フォルダへの画像配置と、`works-data.js` への画像パス項目の追加、`js/work-render.js` / `js/works-list.js` 側の表示ロジック追加が必要になるので、その際はあらためて相談してください。
