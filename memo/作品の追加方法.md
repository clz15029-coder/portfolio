# 作品を追加する方法

WORKS一覧ページ・作品詳細ページ(フルページ版)・作品詳細モーダル(一覧からクリックした時に出る半分パネル)は、すべて `js/works-data.js` という1つのファイルの中身から自動的に作られています。新しい作品を追加するときは、このファイルを編集するだけでOKです(HTMLは触らなくて大丈夫です)。

「業務での制作実績」だけでなく、「個人制作」「イラスト」もすべて同じ`works-data.js`の配列で一緒に管理しています。

## 手順

1. `js/works-data.js` を開く
2. 配列の中にある作品データのどれか1件分(`{ id: '01', ... }` から、対応する `}` まで)を丸ごとコピーする
3. 配列の最後(一番最後の作品データの後、`];` の手前)に貼り付ける
4. 貼り付けたブロックの中身を、新しい作品の情報に書き換える

| 項目 | 説明 |
|---|---|
| `id` | 他の作品と重複しない番号。例: `'30'` |
| `title` | 案件名 |
| `client` | クライアント名。個人制作の場合は「個人制作(◯◯)」のように書く。作品詳細の「Client」欄に表示される |
| `category` | 下記「カテゴリ分類」のいずれかのkey(例: `'web-site'`)。WORKS一覧のフィルタボタンに使われる |
| `tags` | 一覧カードに表示するタグ。例: `['WEB']` |
| `period` | 制作期間。作品詳細の「Year」欄には、この中の年(西暦4桁)を自動で抜き出して表示する。まだ決まっていない場合は`'XXXX(要変更)'`のように仮の値を入れておくと、後で直し忘れを防げる |
| `role` | 担当領域・対応範囲。作品詳細の「Scope」欄に表示される |
| `url` | 公開URL。なければ空文字 `''` のままでOK(その場合、詳細画面のリンク行は表示されない) |
| `summary` | 説明文の1行目 |
| `points` | 説明文の続き。配列でいくつでも追加でき、それぞれ1つの段落として表示される。無ければ`[]`でOK |
| `process` | 制作プロセスのデータ(現在は詳細画面に表示していないが、データとして残しておける)。`{ stage: '見出し', note: '説明文' }` を配列で並べる。無ければ`[]`でOK |
| `images` | (任意)作品画像のパスを配列で並べる。例: `['images/works/01-1.jpg', 'images/works/01-2.jpg']`。1枚目がWORKS一覧カード・TOPページMVランダム表示(`js/hero-visual.js`)のサムネイルに使われる。2枚以上入れると作品詳細ページ(モーダル/フルページ両方)にギャラリーとして並べて表示される。未追記(`[]`)の場合は「作品画像(準備中)」のプレースホルダー表示になる |

5. 保存して commit・push すれば、一覧ページ・詳細ページ・モーダルすべてに自動で反映される

## 書くときの注意点

- 文字列は必ず `'　'`(シングルクォート)か `"　"`(ダブルクォート)で囲む
- 項目と項目の間は `,`(カンマ)で区切る。ただし最後の項目の後にはカンマを付けない
- `{ }` や `[ ]` の数が対応しているか確認する(既存のブロックをコピーして作れば基本的にずれない)
- 1文字でも記号がずれるとページ全体が真っ白になることがある。保存したら一度ブラウザで表示を確認する

## カテゴリ分類

WORKS一覧のフィルタは「大分類3つ→その下に細かい分類」という二階層構造になっています(`js/category-groups.js`の`CATEGORY_GROUPS`で定義)。`works-data.js`の`category`には、下表の**key**を指定してください。

| 大分類 | key | 細かい分類 |
|---|---|---|
| デジタル・Web系 | `web-site` | Webサイト / LP |
| デジタル・Web系 | `ad` | デジタル広告・SNS用素材 |
| グラフィック・印刷 | `pamphlet` | フリーペーパー、パンフレット |
| グラフィック・印刷 | `biztool` | ビジネスツール |
| グラフィック・印刷 | `illustration` | イラストレーション |
| ブランディング・CI/VI | `logo` | ロゴ・シンボルマーク |
| ブランディング・CI/VI | `guideline` | ガイドライン |

該当する作品が1件も無い分類は、一覧のフィルタピルにも表示されません(現時点では`biztool`と`guideline`に該当する作品がまだ無いため非表示)。

新しい大分類・細かい分類を追加したい場合は`js/category-groups.js`を編集してください。

### 卒業制作(wan-idea)について

犬用ベッドのプロダクトデザイン「卒業制作 - wan-idea」は、上記どの分類にも当てはまらないため、ユーザーの意向でWORKS一覧からは一旦除外しています(データも削除済み)。プロフィールページなど別の場所に載せたい場合は改めて相談してください。

## CSVで文章を編集する方法

`js/works-data.js`を直接編集する代わりに、`memo/works-content.csv`をExcel/Googleスプレッドシートなどで編集し、それをClaude Codeに渡して`works-data.js`に反映(流し込み)してもらうこともできます。

1. `memo/works-content.csv`をExcel/スプレッドシートで開く
2. 列は `id, category, title, client, period, role, url, summary, point1, point2, point3`
   - `category`は大分類のkeyではなく、上記「カテゴリ分類」表の**細かい分類の日本語ラベル**(例: `Webサイト / LP`)を入力する
   - `point1`〜`point3`は説明文の続き(段落)。3つまで。それ以上必要な場合は相談する
   - 新しい作品を追加する場合は、一番下に新しい行を追加する(`id`は他と重複しない番号にする)
3. 編集し終えたら、そのCSVファイル(または内容)をClaude Codeに渡し、「このCSVの内容をworks-data.jsに反映して」のように依頼する
4. Claude Code側で`works-data.js`に書き戻し、動作確認・commit・pushする

※ `tags`(一覧カードのタグ表示)は`category`から自動生成されるため、CSVには含めていない。`process`(制作プロセスの詳細データ、現在は非表示)もCSVには含めていないため、既存作品の`process`は差分反映時にそのまま維持される想定。

## PDFポートフォリオから仮登録した実績について

`id: '09'`〜`'29'`の21件(産業廃棄物処理〜60周年記念ロゴ)は、PDFポートフォリオの31〜34ページから仮で登録したデータです。`client`・`period`・`summary`が`'XXXX(要変更)'`や「未入力」のままになっているので、正式な内容に差し替えてください。タイトルも業界名などの仮ラベルのままです。

## 作品画像の登録方法

WORKS一覧カード・作品詳細(モーダル/フルページ)・TOPページMVのランダム表示は、すべて`works-data.js`の`images`配列から自動的に画像を表示する仕組みになっています。

1. 画像ファイルを `images/works/` フォルダに置く(ファイル名は自由。例: `01-1.jpg`)
2. `works-data.js`の該当する作品の`images`に、パスを配列で追加する

```js
images: ['images/works/01-1.jpg', 'images/works/01-2.jpg'],
```

- 1枚だけの場合: `images: ['images/works/01-1.jpg']`
- 複数枚の場合: 配列に並べた順番で表示される。1枚目が一覧カード・MVのサムネイルとして使われ、詳細ページには全部の画像がギャラリー(グリッド)として並ぶ
- 画像がまだ無い作品は`images: []`のままでOK。「作品画像(準備中)」の表示になる

### 画像の書き出しサイズの目安

このサイトには画像を自動で圧縮・変換する仕組みが無いプレーンなサイトのため、書き出したファイルがそのまま表示されます。大きすぎるとページの表示が遅くなるので、あらかじめ以下のサイズ・容量を目安に書き出してください。

| 用途 | 表示比率 | 書き出しサイズの目安 | ファイル容量の目安 |
|---|---|---|---|
| 一覧カード・詳細ギャラリー(1枚あたり) | 4:3 | 長辺1200px程度(例: 1200×900px) | 1枚あたり300KB以下 |
| 作品詳細ページの単体表示(images1枚のみの時) | 16:9 | 長辺1600px程度(例: 1600×900px) | 500KB以下 |
| TOPページMV(images[0]が使われる) | 4:5(縦長) | 長辺1000px程度(例: 800×1000px) | 300KB以下 |

- 表示は`object-fit: cover`という、指定した枠に合わせて画像の中央を基準に自動トリミングする方式なので、上記の比率ぴったりでなくても大きくズレなければ問題なし
- 同じ画像を一覧カード(4:3)とMV(4:5)の両方に使う場合、それぞれ少し切り取られ方が変わる点は想定しておく
- 保存形式はJPG推奨(写真素材の場合)。可能であればWebPの方がより軽くなる
- 上記より小さい分には問題ないが、極端に小さいと引き伸ばされてぼやけて見えるので注意
