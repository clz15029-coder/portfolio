# 作品を追加する方法

このドキュメントは「WORKS(業務での制作実績)」の追加方法です。「PERSONAL WORKS(個人制作)」の追加方法は末尾の [個人制作(PERSONAL WORKS)を追加する方法](#個人制作personal-worksを追加する方法) を参照してください。

## WORKSを追加する方法

WORKS一覧ページ・作品詳細ページは、どちらも `js/works-data.js` という1つのファイルの中身から自動的に作られています。新しい作品を追加するときは、このファイルを編集するだけでOKです(HTMLは触らなくて大丈夫です)。

### 手順

1. `js/works-data.js` を開く
2. 配列の中にある作品データのどれか1件分(`{ id: '01', ... }` から、対応する `}` まで)を丸ごとコピーする
3. 配列の最後(一番最後の作品データの後、`];` の手前)に貼り付ける
4. 貼り付けたブロックの中身を、新しい作品の情報に書き換える

| 項目 | 説明 |
|---|---|
| `id` | 他の作品と重複しない番号。例: `'07'` |
| `title` | 案件名 |
| `category` | `'web'` / `'logo'` / `'print'` / `'banner'` のいずれか。WORKS一覧のフィルタボタンに使われる |
| `tags` | 一覧カードに表示するタグ。例: `['WEB']` |
| `period` | 制作期間 |
| `role` | 担当領域 |
| `url` | 公開URL。なければ空文字 `''` のままでOK |
| `summary` | 一言サマリー |
| `points` | 概要の箇条書き。配列でいくつでも追加できる |
| `process` | 制作プロセス。`{ stage: '見出し', note: '説明文' }` を必要な数だけ配列で並べる |

5. 保存して commit・push すれば、一覧ページ・詳細ページの両方に自動で反映される

### 書くときの注意点

- 文字列は必ず `'　'`(シングルクォート)か `"　"`(ダブルクォート)で囲む
- 項目と項目の間は `,`(カンマ)で区切る。ただし最後の項目の後にはカンマを付けない
- `{ }` や `[ ]` の数が対応しているか確認する(既存のブロックをコピーして作れば基本的にずれない)
- 1文字でも記号がずれるとページ全体が真っ白になることがある。保存したら一度ブラウザで表示を確認する

### 作品画像について(現時点で未対応)

今のところ、WORKS一覧・詳細ページの画像は「作品画像(準備中)」というプレースホルダー表示のままで、実際の画像を差し込む仕組み自体がまだ実装されていません。実際の画像を掲載する際は、`images/works/` フォルダへの画像配置と、`works-data.js` への画像パス項目の追加、`js/works-list.js` / `js/work-detail.js` 側の表示ロジック追加が必要になるので、その際はあらためて相談してください。

## 個人制作(PERSONAL WORKS)を追加する方法

PERSONAL WORKSページ(`personal-works.html`)はWORKSと違い、データファイルを使わず**HTMLに直接書く**方式です。ファイルを開くと、ページ上部にコメントでテンプレートが2種類用意してあるので、それをコピーして使ってください。

- **深掘り型**: 受賞歴や制作背景など、しっかり語れる作品向け。説明文+使用ソフト+外部リンクボタン付き。1つで横幅いっぱいに表示される
- **ライト型**: 画像とタイトル・使用ソフトだけで十分な、軽めの作品向け。説明文やリンクボタンは省略した最小構成。`<div class="light-works-grid">`の中に横並び最大3つまでで表示される

### 手順

1. `personal-works.html` を開く
2. `<section class="page-header">...</section>` の下にあるコメント(`<!-- 作品を追加するときは... -->`)の中から、深掘り型かライト型どちらかのテンプレートをコピーする
3. **深掘り型**はコメントブロックの下、`<div class="light-works-grid">`より前に貼り付ける。**ライト型**は`<div class="light-works-grid">...</div>`の中(既存の`light-work-card`の後ろ)に貼り付ける
4. タイトル、`work-thumb`(画像。準備ができたら`<img>`タグに差し替え)、説明文、`使用ソフト`の内容を書き換える
5. 保存してブラウザで表示を確認し、commit・push する

※ライト型は横並び最大3つまでのレイアウトなので、4つ目以降は自動的に次の行に折り返される

### meta行(使用ソフト・期間など)の書き方

`<p class="work-meta">`は1つのカードに複数行使えます。その作品に合う情報を選んで書いてください。

- 使用ソフト: `<p class="work-meta">使用ソフト：CLIP STUDIO PAINT / Adobe Photoshop CC</p>` のように、`/`(スラッシュ)区切りで複数記載できます
- 期間: `<p class="work-meta">期間：2025年1月〜3月</p>` のように書きます。実際の期間がまだ分からない場合は`期間：XXXX(要変更)`のように仮の値を入れておくと、後で直し忘れを防げます
- 不要な行はまるごと削除してOKです

現在ライト型で並んでいる21件(産業廃棄物処理〜60周年記念ロゴ)は、PDFポートフォリオの31〜34ページから仮で入れた掲載データです。「期間：XXXX(要変更)」の部分は実際の制作時期に差し替えてください。タイトルも業界名や案件の仮ラベルのままなので、正式な案件名に直してもOKです。

### 作品画像について

WORKSと同じく、現時点では画像の差し込み(`images/works/`への配置)は未対応です。実際に画像を載せる際はあらためて相談してください。
