# ポートフォリオサイト制作プラン

**最終ゴール**: GitHub Pagesで公開
**目標時期**: 11月中旬(転職応募開始)までに完成
**実装方法**: Claudeと一緒にJekyllでコーディング(GitHub Pages標準搭載)
**掲載予定案件数**: 6〜10件(前職・現職の2社からピックアップ)
**進行ペース**: 週1回、定期的に区切って進める
**配色イメージ**: 落ち着いたモノトーン寄り
**仕組み**: 作品はJekyllのcollection機能で管理。Markdownファイルを複製して情報を書き換えるだけで一覧・詳細ページが自動生成される

---

## Phase 1: 環境構築(Week 1)
- [ ] GitHubアカウント作成
- [ ] リポジトリ作成(username.github.io 形式)
- [ ] Jekyllのローカル開発環境セットアップ
- [ ] GitHub Pages公開設定の確認(空の状態で一度デプロイテスト)

## Phase 2: テンプレート実装(Week 2〜3)
- [ ] サイトマップ確定(TOP / ABOUT / WORKS / PROCESS・SKILLS / PERSONAL WORKS / CONTACT)
- [ ] 作品用collection構造の設計(フロントマター項目:案件名・カテゴリ・画像・概要・プロセスなど)
- [ ] モノトーン寄りの配色パレット決定(アクセントカラーの有無も検討)
- [ ] フォント選定
- [ ] TOPページ実装
- [ ] WORKS一覧ページ実装(カテゴリフィルタ:WEB / バナー・グラフィック / ロゴ / 印刷物)
- [ ] 作品詳細ページテンプレート実装(ダミー1〜2件で動作確認)
- [ ] 参考サイト(どいせなさん等)のUI要素を反映
  - [ ] 余白・フォントの見せ方
  - [ ] ホバーアニメーション
  - [ ] ページごとのフッターデザイン

## Phase 3: 残りページ実装(Week 4)
- [ ] ABOUT / PROFILEページ実装
- [ ] PROCESS / SKILLSページ実装(対応フロー図、Notion手順化の紹介)
- [ ] PERSONAL WORKSページ実装(軽く)
- [ ] CONTACTページ実装

## Phase 4: 素材の洗い出し・流し込み(Week 5〜7)
- [ ] 掲載する案件を6〜10件に絞り込む(前職・現職から選定)
- [ ] 案件ごとの画像素材を最終整理・トリミング
- [ ] 各案件のプロセス資料(ラフ→承認→完成)を整理
- [ ] Notion手順化ドキュメントのスクショを抜粋
- [ ] 作品を1件ずつcollectionに追加

  - [ ] 案件2

  - [ ] 案件4

  - [ ] 案件6

## Phase 5: 仕上げ・公開(Week 8)
- [ ] レスポンシブ対応チェック(スマホ・PC)
- [ ] 全ページの文言・誤字チェック
- [ ] 表示速度・画像最適化

- [ ] 公開後の動作確認(実機・複数ブラウザ)
- [ ] 独自ドメイン設定(希望する場合のみ)
